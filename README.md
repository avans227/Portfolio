# Personal Portfolio Website

A simple personal portfolio website built using HTML and CSS to showcase my skills, projects, and GitHub profile.

## Features

- About Me section
- Skills section
- Project showcase
- GitHub profile link
- Dark theme with purple accents
- Responsive and clean design
- Hover effects on project cards

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Projects Featured

- Calculator
- To-Do App
- Grade Calculator
- Weather App
- Password Manager

## Project Structure

portfolio/ 
 ├── index.html
 ├── style.css 
 ├── README.md
 └── .gitignore 

## How to Run

1. Clone the repository

bash git clone <repository-url> 

2. Open the project folder

bash cd portfolio 

3. Open index.html in your browser
